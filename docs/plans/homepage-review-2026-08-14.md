## 1. 结论

**修订后通过。** 评审前加权 50 / 72（落在「48–57 修订后复评」区间），按 P0/P1 修订并复测后 **64 / 72（≥58 通过）**。

判定要点：这套页面的问题从来不是「留白不够」——实测整页留白 97.7%，远超 ≥55% 的判据。真正的问题是三件事：

1. **朱红失去语义**：同一个强调色同时承担 eyebrow、章节号、项目号、书类别、此刻序号五种角色，等于没有强调。
2. **节奏均齐**：章节间距是五个互不相关的 `clamp()` 手调值，不构成疏密关系，长页读下来是平的。
3. **和风元素被硬编码色破坏**：宠物与火焰用了 11 个游离于 token 之外的颜色（`#e4002d`、`#ffd65a`、`#f05a24`…），毛玻璃头部与「纸」的物质隐喻冲突。

个人性（D9）从一开始就成立——印章、宠物、`01 /` 编号体例三项缺一不可，占位符测试可辨识。

## 4. 已修订问题

### [P0] D4 朱红被稀释为「小字通用色」，强调失效
位置：`src/styles/global.css` `.hero-eyebrow` / `.project-number` / `.book-kind` / `.now-item > span`
判据：§3.4 渋み — 强调色应有唯一语义
证据：修订前 5 处不同角色共用 `--vermillion`
修订：确立规则「**朱红只属于 章节编号 + 印章 + 交互态（hover/focus）+ 书脊色**」，其余四处改 `--muted`；项目编号改为 hover 时才转朱红
影响：视觉；朱红像素 0.07% → 0.03%（首屏）

### [P0] D5 宠物与火焰有 11 个硬编码色，游离于 token 体系
位置：`src/components/WanderingWalker.astro:932-985`（原 `#050505`、`#e4002d`、`#e43a22`、`#ffb129`、`#ffd65a`、`#f05a24`、`#ffad29`）
判据：§3.4 颜色 ≤6 有效值；§3.5 元素应由体系承担而非贴上去
修订：眼睛与外焰 → `--vermillion`，内焰/余烬/冲击 → 新增 `--ember: #d99a3f`，身体 → `--ink`。火焰从 5 色降到 2 色
影响：宠物仍是同一只，配色进入纸墨朱体系

### [P1] D5 毛玻璃头部与「纸」的物质隐喻冲突
位置：`src/styles/global.css` `.site-header`
判据：§3.5 自然 — 纸不透明
修订：去掉 `backdrop-filter: blur(12px)` 与半透明底，改 `background: var(--paper)` + 实线细边
附带收益：移除一个合成层

### [P1] D1 章节间距是五个孤立手调值，无疏密节奏
位置：`.section` / `#works` / `#books` / `.now-section` / `.about-section`

修订：新增 `--rhythm-1/2/3`（clamp，比例约 1 : 1.6 : 2.6），并按语义编排：项目→写作收紧（同一口气），写作之后放到 `--rhythm-3`（下半页换气），关于结尾同样放大
影响：长页出现呼吸，见 `zh-1440-full-after.png`

### [P1] D8 正文尺度不合中日文标准

## 4b. 定调后的追加修订（2026-08-14 晚）

评审方案 §11 的两个开场问题已由本人定调：**印章保留（可升级）、宠物与小人必须保留（可增加趣味）**。据此追加：

### 印章升级：白文框 → 朱文印（阳刻）
位置：`src/styles/global.css` `.seal`
改动：由「1.5px 朱红细框 + 朱字」改为**实心朱底 + 纸色字**；四角半径不等（`2px 4px 2px 3px`，手刻的石章不是完美方形）；`inset` 阴影模拟印泥边缘不匀；`::after` 加一圈 inset 4px 的留白边栏（篆刻的「边」）。
判据影响：印章成为全页唯一的朱红块面（约 0.4% 像素，仍远低于 ≤2%），符合渋み「一处浓、余处淡」；纸色字 on 朱红对比度 ≈5.3:1，过 AA。
宠物锚点不受影响——`[data-pet-home]` 位置在运行时按 `getBoundingClientRect` 取，印章改样式即自动跟随。

### 宠物趣味化三件（全部在组件层，未动 `src/lib/walker/` 内核与 27 个测试）
1. **眨眼**：每 3.4–7.8 秒随机一次，眼睛纵向压到 0.12，持续 120ms。
2. **指针注视**：鼠标经过 hero 时，若宠物已停稳（`pause`、无互动、无喷火、非跳跃中），转向指针一侧并切到 `observing` 姿态 1.9 秒；冷却 6.5 秒，指针距宠物 <26px 不触发（避免抖动）。触摸设备不触发。
3. **点击轻跳**：宠物是全页唯一接受指针事件的装饰元素（`pointer-events: auto` + `cursor: pointer`）。点击后原地起跳（印章上 13px / 地形上 17px，0.46 秒抛物线 + 落地压缩），同时眨一下眼、好奇心 +0.2；在地形上时有 34% 概率把下次喷火提前到 0.9 秒内。

**实测（CDP 驱动真实 Chrome，非静态截图）**

| --- | --- | --- |
| 场景动画 | 运行 | 停止（静帧） |

| 指针注视后姿态 / 朝向翻转 | `observing` / 已翻转 | `standing` / 未翻转 |

## 6. 记录项（不判对错）

- 整页留白 97.6% 属极端克制。页面**没有任何密度高地**——书架原本应承担这个角色（§6.4），目前仍偏稀。若日后加内容，优先加在书架而非首屏。
